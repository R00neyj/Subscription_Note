# 구독 위시리스트 & 지출 밸런스 시뮬레이터 기능 명세서

---

### 1. 개요 및 목적
- **목적**: 
  1. 결제 전 고민 중인 구독 서비스 후보군을 트래킹하여 충동 결제 방지
  2. 새 구독 추가 시 **"기존 구독 중 무엇을 덜어내야(해지) 예산이 방어되는가?"**를 실시간으로 시뮬레이션하는 양방향 예산 밸런서 제공
- **핵심 원칙**:
  - **입력 마찰 제로 (Zero Friction)**: 우선순위·메모 등 부가 입력을 전면 배제하고, `서비스명`, `카테고리`, `예상 금액(월/연)` 3가지만으로 2초 컷 등록
  - **플랜 교체 차액(Net Delta) 정밀 연산**: 플랜 업그레이드/다운그레이드 시 기존 구독료를 차감한 실질 증감액만 계산
  - **기존 구독 덜어내기(다이어트) 실시간 연동**: 기존 활성 구독 중 해지할 항목을 On/Off 하여 실시간 절감액 및 최종 총 지출액을 즉시 확인
  - **1초 승격 & 공식 링크 바로가기**: 고민 완료 시 공식 사이트 결제/해지 페이지 바로가기 제공 및 원클릭 승격

### 2. 데이터 스키마 명세

#### 1) `subscriptions` 객체 필드 확장
| 필드명 | 타입 | 필수 여부 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| `status` | `string` | **필수** | `'active'` | `'active'` \| `'disable'` \| **`'wishlist'`** |
| `service_name` | `string` | **필수** | `''` | 서비스명 (프리셋 자동완성 지원) |
| `category` | `string` | **필수** | `'OTT'` | 카테고리 ID |
| `price` | `number` | **필수** | `0` | 예상 구독료 (원화 기준) |
| `billing_cycle` | `string` | 선택 | `'monthly'` | `'monthly'` \| `'yearly'` |
| `upgrade_from_id`| `string` | 선택 | `null` | 교체 대상 기존 구독 ID (차액 계산 및 승격 시 기존 항목 자동 비활성화) |
| `created_at` | `string` | **필수** | `ISOString` | 등록 일자 (경과 일수 `D+N` 계산용) |

### 3. 실시간 밸런스 시뮬레이션 연산식

```
1. 가상 도입액 (Simulated Add)   = 선택된 위시 항목들의 월 지출액 (플랜 교체 차액 반영)
2. 가상 덜어내기 (Simulated Cut)  = 덜어내기 선택된 기존 활성 구독들의 월 지출액
3. 최종 순 변동액 (Net Delta)    = Simulated Add - Simulated Cut
4. 예상 총 월 지출 (Final Total)  = 현재 실제 총 구독료 + Net Delta
```

### 4. UI / UX 화면 구성 명세

#### 1) 독립 1급 라우트 (`src/pages/Wishlist.jsx`)
- **경로**: `/wishlist`
- **4분할 실시간 밸런서 카드 (대시보드와 동일한 폰트/패딩 스케일)**:
  1. `가상 도입 (위시)`: `+XX,XXX원/월` (amber)
  2. `가상 덜어내기`: `-XX,XXX원/월` (rose/emerald)
  3. `최종 순 변동액`: `+XX,XXX원/월` or `-XX,XXX원/월` (음수 시 초록 절감 테마)
  4. `예상 총 월 지출`: `현재 XX원 ➔ 최종 XX원/월` (primary blue)

#### 2) 가상 도입 위시리스트 테이블 (`WishlistTable.jsx`)
- 개별 체크박스 지원 (시뮬레이션 포함/제외 토글)
- 서비스명 옆 공식 홈페이지(`Globe`) 바로가기
- 플랜 교체 뱃지 및 차액 표기
- `[구독 시작(교체 승격)]` 및 삭제 버튼

#### 3) 기존 구독 덜어내기 다이어트 패널 (`ActiveCutDietSection.jsx`)
- 기존 활성 구독 목록을 카드로 렌더링하고 `[덜어내기]` 토글 체크박스 제공
- **스마트 다이어트 추천 배너**: 만족도 낮음(`<=3`) 또는 비필수 항목 자동 탐지 및 1클릭 일괄 덜어내기 지원
- **선택 항목 실제 비활성화 버튼**: 시뮬레이션 후 실제 해지 확정 지원

#### 4) 1초 승격 모달 (`PromoteModal.jsx`)
- `[공식 결제 페이지 ↗]` + `[기존 플랜 해지/관리 ↗]` 바로가기 지원
- 결제일 및 결제수단 입력 후 기존 항목 자동 비활성화(교체 승격) 지원
